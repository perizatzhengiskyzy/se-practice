# User stories — Smart Campus study room booking

6 to 8 stories. Keep the shape exactly: ID, the As/I want/so that sentence, a priority, one
assumption. Roles are **Student** or **Administrator** only.


---
### US-01
**Story:** As a Student, I want to view available study rooms, so that I can choose a suitable room.
**Priority:** High
**Assumption:** Blocked rooms are not available for booking.

### US-02
**Story:** As a Student, I want to book an available study room for a selected time, so that I can reserve it for studying.
**Priority:** High
**Assumption:** Students can select from available time slots.

### US-03
**Story:** As a Student, I want to cancel my booking, so that the room becomes available when I no longer need it.
**Priority:** Medium
**Assumption:** Students can cancel only their own bookings.

### US-04
**Story:** As an Administrator, I want to review study room usage over a period, so that I can understand how rooms are being used.
**Priority:** High
**Assumption:** Usage is reviewed for a specified period.

### US-05
**Story:** As an Administrator, I want to block or unblock a study room, so that I can take a room out of service or make it available again.
**Priority:** High
**Assumption:** A blocked room cannot be booked.

### US-06
**Story:** As a Student, I want my room booking to be accepted only when it does not overlap another booking for the same room, so that I can reserve an actually available time slot.
**Priority:** High
**Assumption:** Bookings for the same room cannot overlap.
